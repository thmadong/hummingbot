# BTW 做市 / 跨市场套利 路线图

> 标的：Aster 现货 `BTW-USDT`。价格锚：Binance 永续 `BTWUSDT`。
> 本文记录分阶段计划、风险判断和待定决策，随实现更新。

## 背景

- BTW 在 Binance 合约成交量最大，是最可靠的价格发现场所；Aster 永续价格与 Binance 永续实测偏差
  通常在 0.1% 以内（500 根 1m K 线：均值 +0.006%，极值 ±0.66%）。
- Aster 现货为**新上市市场**，开盘初期盘口为空或极薄，价格发现可能持续数小时到数天。
- 因此策略参考价锚定 Binance 永续，而不是本地中间价；现货盘口稀疏时仍能正常报价。

## 已实现

| 组件 | 说明 |
|---|---|
| `aster` 现货连接器 | EIP-712 API 钱包签名、REST/WS、listenKey 用户流、独立订单状态限流 |
| `pmm_perp_anchored` 控制器 | 锚定 Binance 永续中间价的 10 档做市，每笔 +5% 止盈 / −12% 止损 / 12h 超时 |
| `ops/btw_watchdog.py` | 权益回撤 20%（可配）触发 `hbot stop` 并发邮件；未入金不记基准 |

## 四个阶段

### 阶段 1：纯现货做市（已完成，未上线运行）

- 锚定 Binance 永续中间价，在 Aster 现货挂 10 档。
- 资金：双边合计 2000 USDT，单边 1000。
- 上线条件：Aster 现货双边盘口稳定、观察到足够深度后再运行；**开盘阶段不运行**。

### 阶段 2：单边敞口控制（当前优先项）

目标：在保留做市/收敛能力的前提下，把「基差过大时一次性打满仓」的风险关住。

| 措施 | 说明 | 默认 |
|---|---|---|
| 基础币敞口上限 | 已有持仓 + 活跃买单未成交部分，超过上限就不再新增买单 | 1100 USDT（可在配置里改） |
| 基差护栏 | `\|现货中间价 / 锚价 − 1\|` 超过阈值时暂停新建挂单（已有仓位不动） | 15%（可在配置里改） |

注意：
- 现货做空不可行，因此敞口上限只作用于买侧；卖侧天然受库存约束。
- 暂停报价不等于平仓；已成交敞口仍由三重屏障（止盈/止损/超时）管理。

### 阶段 3：同所对冲套利（Aster 现货 + Aster 永续）

Aster 现货 API 支持现货/合约钱包内部划转：

```
POST /api/v3/asset/wallet/transfer
  kindType: SPOT_FUTURE | FUTURE_SPOT
```

计划：
1. 实现 `aster_perpetual` 连接器（复用现货的 EIP-712 签名与限流骨架）。
2. 现货买入 + 同所永续等量做空，构成现金套利（cash & carry）；反之在溢价时反向。
3. 需要：保证金缓冲、两腿成交对齐（现货 step 1 BTW）、funding 结算周期的实测。

### 阶段 4：跨所套利（Aster 现货 + Binance 永续）

- 优势：Binance 深度与成交量最大，空腿流动性更好。
- 成本：跨所资金调度、保证金管理、两所风控与提币延迟、腿风险。
- 只有在阶段 3 跑顺、且容量确有需求时再做。

## 基差过大时做市策略的风险（备忘）

现货折价（spot << perp）：
- 锚定买档全部高于本地卖一 → 穿价成交，阶梯失效，可能一次性打满多头。
- 卖档远高于市场 → 卖侧永不成交，策略退化为单向买入。
- 折价若因现货才是真价，收敛来自永续下跌，止盈单可能长期不成交。
- 薄盘口下止损市价单滑点远大于设定的 12%。

现货溢价（spot >> perp）：
- 卖档穿价 → 库存快速耗尽；现货无法做空，溢价只能卖已有库存。
- `skip_rebalance: true` 不会自动补货，卖完后策略空转。

共有：
- 穿价成交是 taker（0.07%），正常挂单是 maker（0.02%）。
- 看门狗在现货盘口为空时会回退用永续价计价，权益可能被高估。

## 跨市场套利方法备选（备忘）

| 方法 | 成本门槛 | 风险 |
|---|---|---|
| 现金套利（买现货 + 空永续） | 资金费率 + 基差 | 空腿强平、funding 反转、两腿不同步 |
| 主动吃价差（taker 双腿） | 约 0.12% 来回 + 滑点 | 腿风险、冲击成本 |
| 被动收敛（maker 单腿） | 约 0.04% | 成交不确定、逆向选择 |
| 跨所永续价差 | — | Aster/Binance 永续实测差 <0.7%，扣费后无肉，不建议 |

需先核实：Aster 上 BTW 永续的 funding 方向与结算周期（曾观察到 `lastFundingRate = -0.958%`，
数值可疑，必须先确认，否则「买现货 + 空永续」的收益模型不成立）。
